# Bewijsmap

Deze map bevat bewijsafbeeldingen voor de auditdocumentatie.

## Structuur

| Map | Inhoud |
|---|---|
| `security/` | Bewijs voor security, CI/CD, scanresultaten, SBOM/SCA en repositorybeveiliging |
| `onderhoudbaarheid/` | Bewijs voor onderhoudbaarheid, codekwaliteit, documentatiekwaliteit en testbaarheid |

## Security

| Submap | Inhoud |
|---|---|
| `security/repository-access/` | GitHub Environments, branch protection, rulesets en MFA |
| `security/scanning/` | CodeQL, code scanning en GitHub security settings |
| `security/sbom-sca/` | Dependabot, SBOM en SCA-bewijs |

## Onderhoudbaarheid

Deze map is alvast aangemaakt voor onderhoudbaarheidsbewijs. Voeg hier later screenshots toe die horen bij onderhoudbaarheid, zoals testresultaten, codekwaliteit, documentatiestructuur of technische schuld.
