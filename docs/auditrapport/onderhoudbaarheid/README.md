# Onderhoudbaarheid auditdocumentatie

Deze map is bedoeld voor documenten en bewijs rond onderhoudbaarheid.

Voorbeelden van documenten die hier later kunnen komen:

- onderhoudbaarheidsanalyse;
- codekwaliteitsoverzicht;
- testbaarheidsanalyse;
- technische-schuld-overzicht;
- refactoring- of designpattern-bewijs.

Bewijsafbeeldingen horen in `bewijs/`.
